# Wahl-O-Mat Korrelationen
Basierend auf den Wahl-O-Mat Antworten wird eine Grafik erstellt, in der die Korrelationen der Parteien zueinander basierend auf ihren Antworten gezeigt wird.

Bis jetzt gibt es Code für die Bundestagswahl von 2025 und die Landtagswahl in Sachsen-Anhalt von 2026. Der Code kann aber ganz leicht angepasst werden - nur die Dateinamen mit den Antworten brauchen Anpassungen.
Die Erstellung der Grafik sollte weiterhin funktionieren (man sollte nur schauen, dass man Titel und Achsen evtl ändert).

Ein weiteres mögliches Problem, was Anpassung bedarf, könnte entstehen, wenn andere Parteien zur Wahl stehen. Aber auch das ist recht schnell angepasst.

Der Hauptinhalt ist die Korrelationsmatrix. Für die LTW 2026 wurde aber auch eine Hauptkomponentenanalyse durchgeführt. Basierend darauf wurden die Parteien nochmal grafisch in ihrer Ähnlichkeit dargestellt, in 2-D und in 3-D. Es sollte dringend beachtet werden, dass die Hauptkomponenten nicht interpretiert werden.
Ich persönlich würde nur die Korrelationsmatrix veröffentlichen (zumindest mache ich das vor Wahlen oft im WhatsApp-Status). Die Hauptkomponentenanalyse ist nur Spielerei von mir und führt im Zweifel nur zu Falschinterpretationen, wenn kein gutes statistisches Verständnis von der Methode existiert.
